# Panduan Mendeley: Laporan Bistro Kiosk Nusantara

File terkait:
1. `Laporan_BistroKiosk.docx`: laporan. Sitasi dan Daftar Pustaka masih berupa teks biasa yang bentuknya sudah sama dengan keluaran Mendeley gaya APA 7.
2. `Referensi_BistroKiosk_Mendeley.ris`: 13 referensi untuk diimpor ke Mendeley.

## 1. Impor referensi

1. Buka Mendeley Reference Manager, lalu pilih File → Import Library → RIS, kemudian pilih `Referensi_BistroKiosk_Mendeley.ris`.
2. Pastikan ada 13 entri. Kalau entri tipe web (dokumentasi Microsoft dan Supabase) tidak ikut masuk, tambahkan manual lewat Add Entry → Web Page memakai tabel di bagian 2.
3. Di Word: tab **Sisipkan** (Insert) → **Dapatkan Add-in** (Get Add-ins) → cari "Mendeley Cite" → tambahkan → login.
4. Di panel Mendeley Cite, buka pengaturan gaya sitasi (Citation Style) dan pilih **American Psychological Association 7th edition**.

## 4. Cara mengganti sitasi

1. Blok teks sitasi, misalnya `(Marinakou et al., 2023)`, lalu hapus. Spasi sebelum kurung jangan ikut dihapus.
2. Di panel Mendeley Cite pilih **Sisipkan Sitasi** (Insert Citation), cari judul dari kolom terakhir tabel, lalu klik **Sisipkan** (Insert).
3. Ulangi untuk semua baris tabel.

## 5. Daftar Pustaka

1. Di halaman DAFTAR PUSTAKA, hapus semua entri referensi teks. Baris pertama (link GitHub) **jangan dihapus**.
2. Taruh kursor di baris kosong di bawah link GitHub, lalu di Mendeley Cite pilih **Lainnya** (More) → **Sisipkan Bibliografi** (Insert Bibliography).
3. Rapikan hasilnya: blok semua entri, lalu atur Times New Roman 12pt, rata kiri-kanan (justify), spasi 1,5, indentasi gantung (hanging) 1,25 cm, spasi sebelum dan sesudah paragraf 0, warna hitam, dan hapus garis bawah pada URL.

## 6. Cek akhir

1. Jumlah sitasi Mendeley di dokumen = 18 (sama dengan jumlah baris tabel peta).
2. Jumlah entri bibliografi = 13 (sama dengan jumlah entri di file .ris), ditambah satu baris link GitHub di paling atas.
3. Tekan Ctrl+A lalu F9 dan pilih "Update entire table" supaya nomor halaman di Daftar Isi ikut benar.
